# AWS Architecture Icons

Source: [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/).

Release: July 31, 2026 (2026 Q3).

[Original icon package](https://d1.awsstatic.com/onedam/marketing-channels/website/public/shared/architecture-icon-release/Icon-package_07312026.5846e92413caa21490223536cc97f1269e44fa92.zip)

The 42 SVG files in this directory are unmodified artwork from the official AWS distribution, renamed for local use. `manifest.json` records each original archive path and SHA-256 digest. AWS provides these assets for architecture diagrams and technical materials; the AWS assets remain subject to AWS's applicable terms and are not relicensed by this project.

The official distribution page permits customers and partners to use the assets in architecture diagrams and supporting materials such as presentations and whitepapers. This repository includes them for that diagramming purpose. AWS retains rights in the artwork and trademarks; consult the [official usage information](https://aws.amazon.com/architecture/icons/) when reusing them. This attribution is not a new license grant or a claim that the artwork is open-source.

Glue ETL uses the AWS Glue service icon; Redshift Spectrum uses the Amazon Redshift service icon. Crawler, Data Catalog, and Data Quality use their dedicated resource icons, shown on a light background without altering their artwork. EC2, VPC, Route 53, CloudFront, and Elastic Load Balancing are also included from the same official archive. Unmapped services use a generic labeled node; application/interface icons use Lucide.
